# صندوقنا — تطبيق مستقل (React + Supabase + PWA)

تطبيق يعمل على أي جهاز (هاتف / كمبيوتر) بدون حساب claude.ai، بحسابات دخول وقاعدة بيانات خاصة بك.

## البنية
| الطبقة | الأداة | الدور |
|---|---|---|
| الواجهة | React + Vite + Tailwind | عربية RTL، تثبَّت كتطبيق (PWA) |
| الحسابات | Supabase Auth | بريد + كلمة مرور (ويمكن إضافة Google / رابط سحري) |
| البيانات | Supabase Postgres + RLS | الصلاحيات تُفرض في قاعدة البيانات لا في الواجهة |
| الإيصالات | Supabase Storage (خاص) | الصورة يراها صاحبها والمشرف فقط |
| الاستضافة | Vercel أو Netlify أو Cloudflare Pages | رابط خاص بك، ويمكن ربط نطاقك |

## نموذج الأشهر والمتأخرات
- لكل صندوق `start_month` (بداية احتساب الاشتراكات).
- لكل عضو سجل شهري في `subscriptions`: `paid` / `pending` / `exempt`.
- **شهر بلا سجل بين `start_month` والشهر الحالي = متأخر.** عضو متأخر 6 أشهر وآخر 2 يظهران تلقائياً من العرض `member_months`.
- المشرف يضغط الشهر ليبدّله (متأخر ← مدفوع ← معفي) أو يسدّد كل المتأخرات دفعة واحدة. كل دفع ينشئ قيد اشتراك في السجل المالي تلقائياً، ويُحذف القيد عند التراجع.

## التشغيل خطوة بخطوة
1. **Supabase:** أنشئ مشروعاً على supabase.com ← SQL Editor ← الصق `supabase/schema.sql` ← Run.
2. **Authentication ← URL Configuration:** ضع رابط موقعك النهائي (وبعد نشر الموقع أضف رابطه هنا).
3. انسخ `.env.example` إلى `.env` وضع `Project URL` و`anon key` من Settings ← API.
4. محلياً: `npm install` ثم `npm run dev`.
5. النشر: ارفع المشروع إلى GitHub ثم اربطه بـ Vercel (Framework: Vite) وأضف المتغيرين `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`.
6. على الهاتف: افتح الرابط في كروم ← «تثبيت التطبيق». PWA هنا فيها Service Worker فيعمل كتطبيق حقيقي.

## ما هو جاهز وما هو ناقص
**جاهز:** الدخول والتسجيل، إنشاء صندوق، الانضمام برمز دعوة، الأعضاء، قائمة أشهر السنة والمتأخرات، سداد عدة أشهر، الرصيد، مخطط قاعدة البيانات الكامل (تبرعات، مصروفات بخصوصية، استثمارات، تصويت، إيصالات).
**ناقص (أنجزه مع Claude Code):** انظر `CLAUDE.md`. النموذج التفاعلي الكامل في `prototype/sandoqna-prototype.html` هو المرجع للتصميم والسلوك.

## ملاحظات أمان
- مفتاح `anon` يُكشف للمتصفح بطبيعته؛ الحماية الحقيقية هي سياسات RLS في `schema.sql`. لا تضع `service_role` في الواجهة أبداً.
- راجع السياسات قبل إطلاق صندوق فيه أموال حقيقية، واختبرها بحسابين مختلفين (مشرف وعضو).
- التطبيق يسجّل الحركات المالية ولا ينقل الأموال؛ التحويل يبقى خارجه.
- تحقق من أسعار وحدود الباقات المجانية لدى Supabase والاستضافة قبل الاعتماد عليها.
